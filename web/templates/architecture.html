One model stage. Five deterministic stages.
Deployment
Cloud Run
asia-south1, scale-to-zero, 2 vCPU / 2 GiB.
Container carries a JRE for the validator and poppler for rasterising. The validator jar is sha256-checked at build time — a different binary fails the build.
Identity
sa-reader
The service runs as the reader identity. Application Default Credentials arrive from the metadata server — no key file exists anywhere.
00Source poppler · pdftoppm · 200 dpi
A PDF, photo or scan is fetched and rasterised. Source and page are hashed into the run ledger, so “the model read page 1” is checkable rather than asserted. A text layer, if any, is extracted and never shown to the reader — it exists only to score the read afterwards.
image/png + sha256
01Readers MODEL STAGE
Two models read the same pixels independently, blind to each other. Agreement is never treated as proof — two models can be wrong the same way. Disagreement is treated as proof of doubt. The signal is trusted in one direction only.
gemini-3.7-flash
primary · thinking level low, measured identical to high
gemini-3.5-flash-lite
second opinion · a read under 60% coverage is a failed read, not a disagreement
SourceClaim[] — value, confidence, bbox. never CSV.
02Grid binding NO MODEL geometry
Row, column and service block recovered by clustering bounding boxes — arithmetic with one correct answer. Rows are the stop column in rank order, because the two readers disagree about absolute coordinates by up to two row heights. A run that does not end on the page is withheld whole.
claims bound to (trip, stop, seq, field)
03Disagreement gate NO MODEL
The two reads are compared cell for cell. A claim the readers disagree on is withheld from composition, never resolved by preferring the “better” model — that would reintroduce exactly the failure the gate exists to catch.
admitted claims
04Geocoding NO MODEL OpenStreetMap · Nominatim
Ranked by OSM category, not by popularity — raw importance puts a hardware shop above the town it is named after. Refuses on no match, on a non-place, on ambiguity, and outside the operator’s region. Then the timetable audits the geocoder: road distance is never shorter than a straight line, so a straight line longer than the printed km proves a coordinate is wrong.
claims + coordinates + precision label
05Composer NO MODEL 8 GTFS files
Claims to GTFS. Referential integrity and id uniqueness hold by construction. Schedule arithmetic is not a language task, so no model touches it. Identical claims produce byte-identical bytes.
gtfs.zip
06Publish gate THIRD-PARTY BINARY gtfs-validator 8.0.1
MobilityData’s validator, run on the exact bytes, with the feed’s sha256 bound into the report. Fails closed: a validator that did not actually parse the feed must never read as a pass.
Feed
Zero ERROR notices. Labelled an unofficial development feed in feed_info.txt until an operator adopts it.
Refusal, with the reason
A withheld service, a stop with no defensible coordinate, a dwell that implies the bus parks overnight. Named on screen, never silently dropped.

Why the gate is not enough

The naive baseline — pdftotext plus regex through the same composer, geocoder and validator — also reaches ERROR=0. It publishes three services where HEADWAY publishes two, because the third runs off the page and it cannot tell. Zero errors proves conformance, not correctness.
