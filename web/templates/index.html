Headway

Assam State Transport Corporation · Guwahati Division · Page 1

A bus timetable is not data until someone types it in. This reads the page and refuses when it cannot — because a confident wrong departure time is the one error class no validator on earth catches.

Beat 02 — the run

One model stage. Five deterministic stages.

Everything downstream of the readers is ordinary Python with no model in it. That asymmetry is why the output can be gated on somebody else's binary.

Beat 03 — the verdict

Two feeds. Both pass. One is false.

The same page, the same composer, the same geocoder, the same validator. The only difference is where the claims came from — regular expressions over the PDF's text layer, or two vision readers plus geometry.

Zero errors proves conformance, not correctness.

Page 1 carries three services. The third, Guwahati to Bihpuria, runs off the bottom edge — its last visible row still has a departure time, so the bus does not terminate there. The baseline publishes a 409 km coach service as though it ends at a village halfway along, and gtfs-validator reports ERROR=0 either way. It checks conformance, not whether the bus goes where the feed says. Structure catches what a schema cannot: a completed run ends with an arrival and no departure.
